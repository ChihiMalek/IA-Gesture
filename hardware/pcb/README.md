# PCB

Reserved for PCB design files (e.g. KiCad, Eagle, Gerber exports).

The project report describes a custom PCB design intended to replace the
breadboard prototype (see [`docs/rapport_IA_Gesture.pdf`](../../docs/rapport_IA_Gesture.pdf),
§5.5). The current hardware design assets are the Proteus circuit
schematic in [`../proteus/`](../proteus/) and the enclosure renders in
[`../3d/`](../3d/) — add PCB layout files here once they are produced.
