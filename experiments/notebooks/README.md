# Notebooks

This folder is reserved for Jupyter notebooks (e.g. exploratory data
analysis, model-training experiments, or landmark-visualization notebooks).

No notebook has been added yet — dataset collection and gesture
recognition currently run as plain Python scripts (see
[`src/training/`](../../src/training/) and
[`src/gesture_recognition/`](../../src/gesture_recognition/)). A
third-party sign-language recognition project was used as a reference
during early research and is credited in the bibliography of
[`docs/rapport_IA_Gesture.pdf`](../../docs/rapport_IA_Gesture.pdf), but its
code is not part of this repository.
